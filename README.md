## 📂 Struktur Repositori & Rincian Modul

Repositori ini dibagi menjadi empat direktori utama yang merepresentasikan tahapan esensial dalam pengolahan data. Silakan klik pada setiap tautan direktori untuk melihat dokumentasi lengkap, kode, dan *insight* bisnis dari masing-masing proyek:

### 📊 [Modul 1: Data Analytics Fundamentals & Spreadsheet Mastery](./link-ke-folder-1)
Fondasi pola pikir analitik dan pembersihan data.
* **Highlight:** *Problem Solving Framework* (Issue Tree, Root Cause Analysis), *Data Cleaning & Formatting* skala besar, *Data Validation*, dan *Descriptive Statistics* menggunakan Google Sheets/Excel.

### 🗄️ [Modul 2: SQL for Data Analysis (Tokopaedi Project)](./link-ke-folder-2)
Pengelolaan dan ekstraksi wawasan dari *Relational Database*.
* **Highlight:** Simulasi *e-commerce* fiktif. Mencakup pembuatan arsitektur tabel (DDL), *Data Cleansing & Importing*, hingga kueri analitik tingkat lanjut menggunakan fungsi *Aggregation*, *Subqueries*, dan *Common Table Expressions* (CTE) pada PostgreSQL.

### 🐍 [Modul 3: Python for Data Analysis](./link-ke-folder-3)
Manipulasi dan analisis data *time-series* menggunakan bahasa pemrograman Python.
* **Highlight:** *Interactive Dictionary*, *Data Subsetting*, *Filtering*, dan *Method Chaining* menggunakan **Pandas**. Melakukan pembersihan data mentah hingga visualisasi *Exploratory Data Analysis* (EDA) menggunakan **Matplotlib**.

### 📈 [Modul 4: Data Visualization & Business Intelligence](./link-ke-folder-4)
Transformasi data menjadi presentasi visual tingkat eksekutif.
* **Highlight:** Pembuatan *Dark Mode Interactive Dashboard* menggunakan **Google Looker Studio**. Dilengkapi dengan *Scorecards*, *Dynamic Filters* (Date Range & Dropdown), Geospatial Mapping, dan *Analytical Storytelling* untuk menjawab masalah bisnis secara langsung.
