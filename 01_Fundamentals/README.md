# 📊 Modul 1: Data Analytics Fundamentals & Spreadsheet Mastery

Selamat datang di direktori Fundamental! Bagian ini bukan sekadar tentang menggunakan *tools*, melainkan tentang membangun fondasi yang kokoh mengenai siklus hidup data, **pola pikir analitik (*analytical thinking*)**, dan **tata kelola data (*data governance*)**. 

Di sini, saya mendemonstrasikan perjalanan dari memahami konsep dasar analitik hingga membedah masalah bisnis dan mengeksekusi pembersihan data (*data cleaning*) tingkat lanjut di Spreadsheet.

---

## 🗂️ Rincian Proyek & Portfolio

### 1️⃣ Pemahaman Fundamental Siklus Data (Introduction to Data Analytics)
📄 **File:** `Mini Task 1 - Introduction to Data Analytics.pptx`

Pemahaman kuat mengenai alur kerja seorang profesional data. Pada bagian ini, saya merangkum:
* Pemahaman mendalam mengenai siklus hidup data (*Data Lifecycle*) yang mencakup tahap pengumpulan, penyimpanan, pemrosesan, hingga visualisasi akhir.
* Penjabaran peran strategis data dalam mendukung pengambilan keputusan bisnis (*data-driven decision making*).

### 2️⃣ Pengolahan Statistik Dasar (Basic Statistics)
📄 **File:** `Mini Task 2 - Basic Statistics.xlsx`

Sebelum menggunakan algoritma yang rumit, seorang analis harus memahami perilaku datanya. Tugas ini berfokus pada:
* Penerapan **Statistik Deskriptif** menggunakan fitur Spreadsheet untuk menemukan tendensi sentral (Mean, Median, Modus).
* Analisis sebaran dan distribusi data untuk mengidentifikasi anomali atau pola awal dari sebuah dataset mentah.

### 3️⃣ Pemecahan Masalah Bisnis (Analytical Thinking Framework)
📄 **File:** `Mini Task 3 - Intro to Problem Solving.pptx`

Sebagai seorang data analis, kemampuan teknis harus diimbangi dengan kepekaan bisnis (*business acumen*). Pada proyek ini, saya merumuskan kerangka pemecahan masalah (*Issue Tree & Framework*) untuk 3 studi kasus industri nyata:
* **Kasus E-Commerce/OTA:** Membedah akar masalah anomali lonjakan penjualan akibat *marketing campaign* dan promo *referral*.
* **Kasus FinTech:** Mengidentifikasi penyebab teknis (server/latency) dari lonjakan waktu tunggu transaksi yang memicu keluhan pelanggan.
* **Kasus Digital Marketing:** Menganalisis penurunan konversi akuisisi pelanggan (CAC) di tengah stagnansi anggaran iklan.
* **Skill yang Diterapkan:** *Gap Analysis (Ideal vs Existing Condition), Root Cause Analysis, Hypothesis Generation.*

### 4️⃣ Tata Kelola & Pembersihan Data (Data Cleaning & Validation)
📄 **File:** `Mini Task 4 - Data Formatting and Validation.pptx` & `Mini Task 4 - Dataset Supperstore.xlsx`

Data yang buruk akan menghasilkan keputusan yang buruk (*Garbage In, Garbage Out*). Dalam tugas ini, saya mensimulasikan peran *Data Steward* pada dataset operasional "Superstore" dengan mengimplementasikan standardisasi data tingkat lanjut di Spreadsheet:
* **Automated Text Cleaning:** Menggunakan kombinasi rumus `ARRAYFORMULA` dan `PROPER` untuk merapikan ribuan baris teks (kategori produk & region) secara instan.
* **Conditional Formatting:** Merancang sistem deteksi visual otomatis (highlight merah) untuk transaksi yang menghasilkan *Profit* negatif (kerugian).
* **Data Deduplication:** Mengidentifikasi dan menghapus data ganda (*duplicate rows*) secara sistematis untuk menjaga integritas database.
* **Data Validation:** Membangun *drop-down list* terstruktur pada kolom Segment untuk membatasi *human-error* (salah ketik) saat proses *data entry*.
